# 👋 Портфолио системного аналитика

> Здесь я фиксирую и веду проекты по системному анализу — от интервью с заказчиком до диаграмм, спецификаций и прототипов, — а также описываю пошаговые инструкции по инструментам, которыми пользуюсь в работе.

---

## О профиле

Это репозиторий-портфолио на GitHub, который решает две задачи:

- 📁 **Ведение проектов** — учебные и практические кейсы по системному анализу: сбор и документирование требований, построение диаграмм (Use Case, DFD, ER, диаграммы последовательности), проектирование данных, постановка задач разработчикам.
- 📚 **Инструкции по инструментам** — пошаговые гайды по инструментам и рабочим связкам, которые упрощают ведение документации и заметок.

Каждый проект оформлен отдельным файлом: контекст задачи, что было сделано, ссылки на итоговые материалы (диаграммы, спецификации, прототипы) и чему проект учит.
