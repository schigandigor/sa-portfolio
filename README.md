# 👋 Портфолио системного аналитика

> Портфолио проектов по системному анализу и проектированию ИИ-ассистентов. Здесь собраны требования, модели данных, диаграммы, задачи для разработчиков, прототипы и материалы по ИИ-системам.

---

## О профиле

Здесь собраны учебные и практические кейсы в двух направлениях:

- 📁 **Системный анализ.** Сбор и описание требований, модели данных, диаграммы, задачи для разработки и прототипы. В командных проектах отдельно описываю свою роль и вклад.
- 🤖 **ИИ-системы и ассистенты.** Проектирование персональных ассистентов в Claude Projects и подготовка учебных материалов по ИИ-системам.
- 📚 **Инструкции.** Пошаговые руководства по инструментам, которые использую для работы с документацией и заметками.

В карточках проектов указаны задача, выполненная работа и ссылки на доступные артефакты.
