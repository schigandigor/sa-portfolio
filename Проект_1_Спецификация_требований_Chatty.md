# 📋 Спецификация требований к ПО - Chatty 2.0

> Проект по системному анализу: разработка спецификации требований для второго релиза учебного приложения по изучению английского языка.

**Роль:** системный аналитик

**Инструменты:** Google Docs,  UML Use Case (draw.io)

---

## О проекте

**Chatty** - это веб-приложение для изучения английского языка.

В первой версии продукта был доступен только словарь для поиска и сохранения слов. Во втором релизе в спецификацию требовалось добавить две новые функции:

- карточки для запоминания слов;
- просмотр видео с примерами употребления слов.

Я взял уже начатую спецификацию и довёл её до конца — от диаграммы вариантов использования до атрибутов качества, бизнес-правил и глоссария.

---

## Что сделано

### 🗂️ Карточки для запоминания слов

На основе готовых вариантов использования (ВИ-8, ВИ-9, ВИ-10) написал функциональные требования по трём группам:

1. создание карточки из слова в словаре;
2. удаление карточки;
3. режим обучения - это показ карточек по очереди, отметка «Помню / Не помню», учёт результата для повторений.

### 🎬 Просмотр видео

Добавил новый вариант использования **ВИ-11 «Посмотреть видео»** с базовым сценарием и тремя расширениями:

- видео недоступно;
- нет информации об авторских правах, в этом случае воспроизведение блокируется;
- ошибка при воспроизведении.

Плюс два дополнительных сценария:

- субтитры к видео;
- смена качества видео.

Диаграмму Use Case обновил, добавив в неё:

- просмотр видео;
- субтитры;
- выбор качества видео.

Функциональные требования к видео разбил на пять групп: просмотр, управление воспроизведением, настройки качества, субтитры, авторские права.

### 📐 Атрибуты качества

| Категория | Требование |
|---|---|
| Юзабилити | Тач-таргеты плеера — от 44×44 px |
| Производительность | Загрузка видео — не дольше 5 сек |
| Производительность | Смена качества — до 2 сек |
| Производительность | Буферизация без обрывов при скорости от 5 Мбит/сек |
| Безопасность | Доступ к правкам авторских прав — только у администратора |

### ⚖️ Бизнес-правила

1. Видео должно быть доступно из подключаемой библиотеки.
2. Источник и автор видео указываются в обязательном порядке.
3. Показ видео без действующей лицензии запрещён (со ссылкой на ГК РФ и юридический отдел).

### 📖 Глоссарий

В глоссарий добавлены термины:

- «подключаемая библиотека видеофайлов»;
- «лицензия на видео»;
- «автоматическое качество».
