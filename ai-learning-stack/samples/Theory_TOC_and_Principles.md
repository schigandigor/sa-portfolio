## Ключевые принципы 2026 (сжатая выдержка)

1. **Маршрутизация вместо монолита** - это router + specialists, не одна модель на всё.
2. **Чистота когнитивного носителя** - это лаконичное System Core.
3. **Экономика Test-Time Compute** - это глубокое рассуждение только там, где высока цена ошибки.
4. **Разделение Memory и RAG.**
5. **Открытые стандарты интеграции** - это MCP (в т.ч. 2026-07-28), HITL на актуаторах.
6. **Гибридный поиск как база**; GraphRAG по необходимости.
7. **Constraints ≠ Policies** - это запреты и операционные правила в разных слоях.
8. **Web: opt-in + label + Non-Merge.**
9. **Наблюдаемость** - это состояния, tool calls, cost.
10. **SLO на уровне всей задачи**, не одного вызова модели.
11. **Явное определение шага** и лимит автономии с эскалацией.
12. **Golden set / regression** при изменении ядра или KB.
13. **MCP ≠ A2A** - это разные уровни протоколов.
14. **Корпоративная идентичность инструментов** - это IdP, gateway, без секретов в промпте.
15. **Дисциплина Design Pipeline** - это dual gate, NFR, безопасная выдача артефактов.
