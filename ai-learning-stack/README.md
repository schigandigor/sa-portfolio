## Как читать (кратко)

| Роль | С чего начать |
|------|----------------|
| Архитектор / SA | Теория → Глоссарий → Практика (разделы про design pipeline и чек-листы) → Экосистемы |
| Разработчик | Глоссарий → Практика → фрагменты Теории → Экосистемы (API, лимиты) |
| Менеджер / PM | Ключевые принципы Теории → стадии rollout в Практике → сравнение платформ в Экосистемах |

Подробнее: раздел «Как читать стек» в Теории (в samples).
