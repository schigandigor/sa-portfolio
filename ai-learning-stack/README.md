## Важно про Экосистемы

Цены, модельные ID, лимиты и функции поставщиков меняются. Публичный обзор фиксирует выбранные характеристики по первичным источникам на дату сверки 2026-10-28 и намеренно не является полным внутренним справочником.

- Модель в API и модель в пользовательском приложении могут иметь разную доступность и лимиты.
- Кеширование, длинный контекст, инструменты, регион обработки и специальные режимы могут менять итоговую цену.
- Перед выбором платформы и расчётом бюджета сверяйте текущие страницы поставщика и конкретный API ID.
- Субъективные оценки и неподтверждённые сообщения не выдаются за доказанный дефект платформы.
